# Firewall datasheets

Vendor datasheets and end-of-life notices for Cisco, Fortinet and Palo Alto Networks
firewall appliances. These are the source documents for the Firewall Sizing Bench: each
model name in the sizer links to its datasheet here.

Every figure in these documents is a vendor lab number published as "up to". Archived
FortiGate datasheets (`archived-*`) are no longer published by Fortinet and are kept for
reference only.
